# Code and Methods

This folder contains the implementation and prespecified methods for the
independent HipMRI study. The package `hipmri_rewrite` defines data validation,
geometry-preserving preprocessing, PyTorch models, losses, inference,
overlap/boundary metrics, and pretraining audit/profile commands. `config/`
contains the fixed patient split; `tests/` contains synthetic contract tests.

The available model implementations live in
`hipmri_rewrite/models/baseline_2d.py`, `baseline_3d.py`, and
`improved_3d.py`. Their provisional identity records are in
`config/arms/<arm_id>/arm.json`. These records reserve separate experiment
spaces; they do not prescribe training settings before the real-data audit.
The 3D arms are the primary future comparison; the 2D arm is retained as
background work.

Run from this `code` directory in the existing Python 3.11 `torch` environment:

```text
python -B -m unittest discover -s tests -v
```

The study hypotheses and evaluation rules are in
[`docs/STUDY_PROTOCOL.md`](docs/STUDY_PROTOCOL.md). The provenance of each
architectural or data decision is in
[`docs/SOURCE_DECISIONS.md`](docs/SOURCE_DECISIONS.md). Real-data and GPU
gates are in [`docs/EXECUTION.md`](docs/EXECUTION.md), while commands for the
student's two separate terminals are in
[`docs/RANGPUR_COMMANDS.md`](docs/RANGPUR_COMMANDS.md).

The source-only transfer ZIP is generated by `python tools/package_transfer.py`
and stored under `transfer/`. It excludes raw logs, medical-derived results,
weights, NIfTI data, and the generated project map. Regenerate the latter on
Rangpur after unpacking. The study is an annotation-assistant prototype, not
a source of clinical contours.
