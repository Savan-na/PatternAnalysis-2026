# v3 三分支对照训练：C / L / S

日期：2026-10-21。状态：代码和配置已准备，尚未提交远端训练。所有新结果放在独立 v5 区域。

## 研究问题和唯一变量

| 分支 | 网络与训练 | 相对 C 的唯一干预 | 待检验的收益与风险 |
|---|---|---|---|
| C：同期对照 | 原始 v3 GN1 残差、三头 logits 相加，Adam 0.001 | 无 | 验证新训练入口能否重现历史 v3；硬件和随机内核仍可产生差异 |
| L：类别权重 | 与 C 相同 | 三个小器官 CE 权重取平方根 | 或能改善 precision、减少过分割；也可能降低 recall 和 Dice |
| S：学习率 | 与 C 相同 | 每次更新后设置余弦学习率，0.001 衰减至 0.00001 | 或能稳定后期优化；也可能过早衰减而欠拟合 |

类别顺序为 Background / Body / Bones / Bladder / Rectum / Prostate。

- C/S CE 权重：`[1.453871, 1, 2.617199, 4.498586, 8.893215, 9.69995]`。
- L CE 权重：`[1.453871, 1, 2.617199, 2.120987, 2.982149, 3.114474]`。
- PyTorch weighted CE 使用加权均值，调整少数类权重也会改变归一化分母；不能解释成只修改这些位置的独立梯度。
- 三组均为 `0.5 weighted CE + 0.5 foreground soft Dice`，对三头相加结果计算。
- S 保留 Adam、weight decay=0，不混入 A0/A1 的 AdamW 和权重衰减。

三组相同 seed=371017、同一 v3 初始权重摘要、Train 患者/visit/patch 顺序、batch=2、50轮、每轮130次更新，总计6500次；不增加空间或强度增强。沿用固定预处理、推理和患者划分。C 的 CPU 网络一步更新必须与原始 v3 目标数值完全一致。

## 选择、比较与判定

每5轮评估完整38个 Validation volume；十个候选中按原患者均衡三个小器官 Dice 选择最高者，同分保留早轮次。比较各分支自己的 best，不默认第50轮。首要比较 L−C、S−C，历史 v3 作为补充。

记录六类 confusion，可计算 Dice、IoU、precision、recall；五个前景类表面距离/HD95/ASSD、远处 Background→Body 误报、患者差异、训练/验证耗时和显存。每批另记录 CE、Dice、梯度范数和实际学习率。六类回退与异常尾部必须报告，不以更低训练 loss 宣称更优。

本轮不读取 Test 图像或标签，不用既有 Test 成绩选择权重。筛选有收益的候选后，以匹配的第二种子重复 C 与候选，确认收益和代价。单种子两项筛选不构成统计显著性或外部泛化证据。若 C 相对历史 v3 明显漂移，先核对环境和同期表现再解释干预。

原先建议的额外病例可视化不作为启动训练的无止境前置诊断。训练后对各自 best 做相同 Validation 病例的图像审阅，重点检查 precision/recall 变化、异常连通区域、器官端部与 Body 边界。


某分支失败后，先查看日志、确认空间且所有 v5 作业已退出，再按分支恢复：`resume-C`、`resume-L` 或 `resume-S`，替换上述命令的 `new`。恢复不重新设定余弦周期，核对源码、配置、参考记录、运行时版本、优化器、学习率与累计更新数，并恢复随机状态。不会自动改变预算或覆盖其他分支。
