# Cohort-Wide MRI–Label Alignment

These 26 contact sheets cover all 143 Train MRI/Mask pairs. Each scan contributes
one axial slice through the Prostate and one through the Bladder to screen for
gross alignment problems across patients and weeks. No obvious whole-image/mask
shift was seen in the displayed slices. This screen does not check every slice
or certify fine contour boundaries.

The audit index in `logs/audits/` retains the original Rangpur output paths;
these local images were grouped here afterward without changing image bytes.
