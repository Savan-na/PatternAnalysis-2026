# 四例Validation图片审阅

已在本地逐张查看8张PNG。来源为Rangpur作业678349；四例×四checkpoint的整卷混淆矩阵均在绘图前精确复现。下载的provenance中，四组epoch JSON与manifest的8项SHA与本地文件一致，详见`local_verification.json`。PNG目前只有本地哈希，尚无独立远端图片哈希清单。

## 看图方法

六类图：四行分别为Standard、v1、v2第45和50轮；每类选择GT面积最大的轴向切片，四模型共用相同位置。青色GT、橙色预测、红色假阳性、蓝色假阴性。**各列可能来自不同z，不能当成同一张完整多类分割图。** 对Background而言，蓝色表示真实背景被预测为其他类，不必然都是Body。

Body图：三个方向穿过v2第45轮最远Background→Body误报位置，四模型共用切片。某些冠状/矢状面完全位于身体之外，Standard一行接近空白是切片位置的结果，不是MRI缺失。它们刻意展示远处失败，不代表中心器官或整体准确率。

## 实际观察

| 病例 | 图中可见现象 | 可得结论与限制 |
|---|---|---|
| S022_Week2 | 两个v2轮次均有身体之外的Body小岛；第50轮若干外部区域更大。六类最大面积切片中的器官位置仍大体接近GT | 不能因为器官中心切片看似接近，就否认整卷分数退步。整卷计数揭示大量新增小器官假阳性，见下表 |
| K018_Week4 | v1与v2均有远处Body误报；v2第50轮在共同冠状/矢状切片上出现较广泛的误报区域 | 独立监督没有消除远处错误；这些切片不能用于估计全卷误报总量或归因归一化 |
| M030_Week0 | v2第45轮在所示冠状平面较v1少一些误报区域，但仍有分离误报；第50轮仍未清除 | 允许局部改善与残余失败同时存在。患者层面改善不能保证每周每切片均改善 |
| J026_Week4 | v2第45轮所示冠状面仍有大片远处Body误报；器官中心切片与GT可保持接近 | 支持Body错误与局部小器官重叠可以同时出现，不能仅用小器官Dice选出边界可靠模型 |

## S022_Week2：以完整混淆矩阵解释图片未覆盖的退步

| 类别 | TP：45→50 | FP：45→50 | FN：45→50 |
|---|---:|---:|---:|
| Bladder | 2,633→2,597 | 613→8,887 | 123→159 |
| Rectum | 1,293→1,220 | 677→3,113 | 86→159 |
| Prostate | 730→767 | 524→1,450 | 124→87 |

Bladder第50轮FP主要来自GT Body（7,891），另有981个来自Background；Rectum FP中2,888个来自Background；Prostate FP中869个来自Background。尤其Prostate的TP增加、FN减少但Dice仍下降，直接说明该例不能解释为单纯漏检。

以上计数来自整卷JSON，而非截图估算。它们尚未定位每一个小器官FP的空间分量；当前最大面积切片并未覆盖所有错误位置，不声称已看见全部FP。该例机制也不能自动推广到所有患者。

**审阅结论：不以v2替换v1，不追加训练。** 这次改动改变了一部分错误取舍，但没有达到Body边界和器官保持标准。下一阶段如继续，只能明确检验一个因素，并继续避免Test调优。所有版本先保留证据，未执行删除或归档。
