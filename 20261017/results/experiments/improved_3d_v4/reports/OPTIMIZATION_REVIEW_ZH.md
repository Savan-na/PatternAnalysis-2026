# 常用优化方法补充审查与 v4 训练方案建议

> 后续执行更新：下文为候选讨论。用户随后选择了A0/A1空间增强配对实验，具体见[冻结协议](../../../../code/docs/V4_Paired_Training_ZH.md)。两组已提交；本次没有强度增强，也没有CE权重压缩。下文“v4-A/v4-B”是旧候选命名，不等于当前A0/A1作业身份。

日期：2026-10-20。接续《Best_Checkpoint_Methods_and_Assessment_Review_ZH》。这是待冻结的方案建议，不是已经执行或有效性的结论；没有修改历史训练配置、权重或选模规则。

## 1. 当前真正遗漏了什么

五个模型的正式训练均为固定 Adam 学习率 0.001、weight decay=0、无正式空间/强度增强。Adam自身的逐参数自适应不等于学习率调度。患者均衡、加权CE、Dice、归一化、残差、Dropout和深监督已有实际应用，不能列为全部缺失。

这些遗漏足以说明：我们还没有充分优化训练配方，不能仅凭更复杂网络就期待全面超越 Standard。也不能据此认定固定学习率就是 v2 后期下降、v3 Bladder 误报的原因。

## 2. 常用方法清单：收益、风险与优先级

| 方法 | 主要目的及项目依据 | v4 建议及风险 |
|---|---|---|
| 学习率调度 | 后期减小更新幅度；现有所有正式训练未采用 | 第一优先。选一种平滑衰减并冻结；逐epoch和逐batch都可，逐batch本身不保证更好。过早降至很低会欠拟合 |
| 配对3D空间增强 | 降低对姿态、位置及有限患者的依赖 | 第一优先。小旋转、缩放；MRI与mask完全同变换，mask最近邻插值。先验证方向和标签语义，再考虑翻转；不能随意上下翻转或强弹性形变 |
| MRI强度增强 | 提高对对比度、噪声和采集差异的适应 | 第一优先。温和乘性强度、噪声；不能把标准化后的负值直接送入gamma。背景处理不使用GT定义推理区域 |
| AdamW权重衰减 | 抑制参数过度拟合；当前为0 | 高优先候选。初始候选1e-5，卷积权重施加，bias/归一化参数排除；这与论文Adam加L2并非完全相同 |
| 类别权重温和压缩 | v3 Bladder主要是Body→Bladder误报，需检查precision/recall取舍 | 单独配对候选：原CE权重开平方，保留Dice。不直接取消小器官支持；原因尚未证实 |
| 采样中的困难背景/边界 | 增加错误区域相关曝光 | G7只通过曝光审计，未证明训练收益。作为后续候选；不可同时无条件增加器官过采样和类别权重，可能加重FP |
| 边界或surface loss | 针对薄边界、base/apex，而非仅重叠 | 需先确认错误集中于边界；物理距离、空类别处理和损失量级须验证。暂不直接加入主配方 |
| Focal/Tversky及其变体 | 调整困难体素或FP/FN代价 | 已有明显FP问题，不能默认继续强化召回。需要明确目标及权重，非必然优于现有CE+Dice |
| EMA / SWA | 平滑参数轨迹，可能减少末期波动 | 第二优先；分别保存普通/平均权重并用相同Val规则选模，增加状态及候选数量，不能保证改善 |
| 梯度裁剪 | 防止异常大更新 | 先查看梯度范数；无爆炸证据时不宣称提高泛化。若启用记录裁剪比例，不能掩盖NaN |
| Warmup | 缓解训练起始不稳 | 当前无明确起始不稳定证据，不作为必需项；不能与衰减混为一谈 |
| 更大patch/更高分辨率/各向异性卷积 | 更完整空间上下文及细边界 | 可能有价值，但改变物理视野、算力和采样分布；独立资源预检后研究，不能仅因显存空闲就增大batch |
| 调整Dropout/网络容量 | 平衡表达和正则化 | 现有Dropout0.3已存在；增加正则化不一定更好，可能欠拟合。暂保留v3结构 |
| TTA/模型集成 | 减少部分预测方差 | 作为单独推理方案，报告额外耗时；不能冒充单模型结构改善 |
| 连通组件后处理 | 去除离散误报 | 先做Validation独立诊断，防止删掉正确结构；不得用GT限制预测区域 |
| AMP、缓存、数据加载优化 | 提高吞吐、节省显存 | 工程优化；不宣称本身提高准确率。变更精度要检查数值及恢复一致性 |
| 多seed、患者级交叉验证 | 量化随机性及泛化不确定性 | 高研究价值，不能把更多同患者切片当独立样本。预算允许优先复核胜出配方，而非无限模型搜索 |
| 每epoch验证、早停 | 更及时观测、避免自动使用最后一轮 | 可提高观察密度，但更多候选也增加选择偏差。若v4逐轮选best，需同样重评控制模型所有50个epoch；否则主比较保持每5轮选模 |

标准化处理强度尺度；正则化控制拟合；采样/loss处理训练中的类别贡献。三者功能不同，不能互相替代，更不能保证解决标注噪声、分布偏移及空间错误。

## 3. 三篇参考论文给出的直接提醒

- [U-Net 2015](https://arxiv.org/pdf/1505.04597)：数据增强和加权损失是其训练设计的重要组成；接触细胞边界权重不能直接照搬成盆腔器官loss。
- [3D U-Net 2016](https://arxiv.org/pdf/1606.06650)：强调配对体积增强、类别加权及稀疏标注处理；我们完整标注中的Background不能按未标注区域屏蔽。
- [Isensee 2018，§2.1](https://arxiv.org/pdf/1802.10508)：同时采用随机patch、Dice、增强、学习率衰减和weight decay。我们采用了部分结构，却遗漏了这些训练配方。论文的多头logit相加本来就是其设计，不能直接称为实现错误。
- [AdamW原论文](https://arxiv.org/abs/1711.05101)：说明Adam的L2惩罚与解耦weight decay不同；支持将AdamW作为候选，不构成HipMRI有效性的保证。

## 4. 修订 v4：先优化训练配方，再考虑加网络模块

建议把v4定义为“v3结构 + 优化训练配方”，允许组合多个合理方法。该组合若改善，只能归因于整体配方；不能声称每一项都贡献了多少。

**建议首轮 v4-A：**

1. 保留v3的GN、残差、原相加深监督、输入分辨率、患者均衡采样及CE+Dice原权重。
2. AdamW，初始lr=0.001，weight decay候选1e-5，bias/归一化参数不衰减。
3. 50epoch、130更新/epoch，共6500次更新。按已完成更新数t使用cosine：`lr(t)=1e-5 + 0.5*(1e-3-1e-5)*(1+cos(pi*t/6500))`。首次更新t=0，最后一次更新t=6499；t=6500为训练结束状态。此为项目候选，非三篇论文原样复现。
4. 温和增强初始候选：每patch以0.3概率应用各轴±10°旋转和0.9–1.1缩放；以0.3概率乘0.9–1.1强度，以0.15概率加标准化尺度下std=0.03的高斯噪声。参数须经过Train可视化和成对几何检查后冻结；不在Test上调节。
5. 空间增强使用有余量的源区域再裁剪，MRI线性/mask最近邻；记录增强后器官消失、裁剪和背景统计，避免人为损害小器官。强度增强保留MRI有效支持区域语义，不使用GT决定背景。

**v4-B：** 同一配方、相同初始化与样本/增强随机序列，仅将CE权重开平方。这样可区分压缩权重在新配方中的增益，而不是把所有收益都归给loss。若预算只够一次正式训练，先v4-A，不能将未执行的B写成有效。

v3历史结果提供实用参照；若要拆分调度、增强、AdamW各自效果，再做对应移除实验，不要求现在穷举所有组合。胜出后优先补至少另一个seed；单seed胜出不支持“全面稳定超越”的结论。新增算力成本应记录真实GPU时间。

## 5. 评价、停止与复现约束

- 主比较统一使用50epoch内相同验证频率、相同患者等权小器官Dice选择的best。保留v2第45轮；最后一轮只作稳定性诊断。新方案从头训练，不把续训额外步数作为等预算提升。
- 同时报告六类Dice/IoU、precision/recall、患者差异、Body远处FP、逐类HD95/ASSD、base/apex、真实失败图、显存及推理时间。不能用更低loss代替分割证据。
- 以Standard小器官Dice0.8502、v3约0.8564及六患者差异为参照；同时检查Bladder恢复和Body尾部错误。预先冻结临床边界及每类退步容忍条件，再提交训练；平均分提高但关键类明显退步应称取舍。
- 调度器、optimizer、随机数、增强采样状态随checkpoint保存；恢复前核对模型、loss、配置、数据划分、更新数和LR。验证中断恢复后的下一批数据/增强/LR一致性。
- 已查看Test仅用于冻结模型后的描述性检验，不反复决定v4超参数。Validation仅6患者，多轮模型选择同样有过拟合风险；没有外部新患者时，不宣称已经证明域外泛化。

# v4预案：在新Test评估前固定的Train/Validation方案

日期：2026-10-20。**仅依据Train与Validation制定；未训练v4。** 此文的SHA将写入即将进行的固定权重泛化审计，避免把新Test结果转化为v4选择依据。当前为条件性预案，实施前仍需完成v3 Validation图像审阅；若Validation证据不支持，只可停止，不以Test结果改选方案。

## 1. 推荐研究问题

v3保留了残差与相加深监督，以GN(1,C)替换IN后，Body错误大幅改善，但六患者的Bladder Dice均较v1下降。完整Validation矩阵显示v3 Bladder FP为22,187，v1为15,002；其中Body→Bladder为21,432与14,680，TP仅由216,111变为215,673。这支持检验**类别权重与稀有器官预测精确率的取舍**，尚不能证明类别权重就是误判原因。

下一项若获准执行，建议v4以v3为控制，只压缩CE类别权重的动态范围；不改归一化、残差、深监督、采样、分辨率、增强和学习率。

## 2. 唯一拟议改动

保持 `L = 0.5 * CE + 0.5 * foreground_soft_Dice`，将原CE权重逐项开平方：

| 类别 | v3 CE权重 | v4候选，约数 |
|---|---:|---:|
| Background | 1.453871 | 1.20577 |
| Body | 1 | 1 |
| Bones | 2.617199 | 1.61778 |
| Bladder | 4.498586 | 2.12099 |
| Rectum | 8.893215 | 2.98215 |
| Prostate | 9.699950 | 3.11447 |

实际冻结配置应使用由原向量计算的完整精度平方根，不手工抄录约数。这是预先选定的一种温和压缩，不扫描指数或权重。

为什么不全设1：历史Standard两patch实验中取消权重曾导致小器官学习失败，虽然它不能直接推广到v3，但支持避免第一次就完全取消补偿。平方根仍保留稀有类较高权重，同时降低约9.7倍的最高相对权重至约3.11倍。**没有论文或本项目数据保证平方根最优；它是可证伪的工程干预。** Dice继续提供宏平均前景信号。

PyTorch加权CE按当前目标的权重总量归一化，因此新loss数值不能与v3直接比大小，也不能简单声称某类梯度固定减少一半；需记录各类预测、FP/FN、梯度与原始loss项。

## 3. 控制条件

- 从匹配初始权重/随机状态重新训练，不能续训v3第50轮后与原50轮混比。
- v3网络、GN(1,C)、Dropout0.3、三头logits相加，全部保留。
- 相同26患者日程、uniform patch、64×64×32 XYZ、batch2、Adam1e-3、50轮6500更新；不同时加入边缘采样或增强。
- v3第50轮为主要对照。原小器官checkpoint选择不变，固定末轮与best分开报告。
- v4单独保存源码/冻结配置/initial与每轮权重/metrics；不覆盖v3。

## 4. 在训练前应冻结的工程判断标准

建议针对固定第50轮采用以下门槛；属于研究判断，不是临床阈值：

1. 相对v3，患者等权Bladder Dice提高至少0.01，至少4/6患者改善；同时Bladder precision提高，recall下降不得超过0.01。
2. Body卷HD95中位数≤6mm，且不得新增高于v3最差21.51mm的病例；患者等权远处Body误报率不得高于v3的0.3649%。
3. 患者等权小器官分数不得低于v3超过0.005，其他前景类Dice不得低于v3超过0.01；列出每名患者全部退步。
4. 具体评估base/apex漏检、Rectum precision/recall、分离分量与面积过渡；不能仅以Bladder FP减少判成功。
5. 若Bladder提升完全由召回损失或其他器官退步换取，不接受；若无改善，削弱“CE权重压缩可修复此问题”的假设，停止继续权重搜索。

这些条件不能用新Test反复调整。若Validation图像揭示标签/空间问题，应先暂停并处理证据有效性，不凭该Test患者的特殊模式定制模型。

## 5. 泛化与预算

单次50轮预计约2 GPU小时量级，未提交。先完成固定模型审阅，不预订自动v4训练；不进行多权重、多seed并行搜索。只有有价值的Validation结果才考虑匹配额外seed，并报告反复使用Validation造成的乐观偏差。

当前Test已被多次查看，新增固定模型Test评估只支持描述已知保留患者上的表现，不能证明新的独立泛化或指导v4。真正独立最终泛化仍需未见新患者；若没有，就明确结论上限，不虚构新Test。
