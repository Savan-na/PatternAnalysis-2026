# 下一次模型提升方案：从 v3 出发，检验过分割与异常连通预测

日期：2026-10-21。状态：**研究建议，未冻结、未实现新训练、未提交GPU作业。**

## 1. 建议摘要

下一次训练建议命名为 **Improved v5-L：保留v3网络，仅弱化三个小器官的交叉熵类别权重**。先用一次很小的固定Validation图像诊断确认极端前列腺错误形态，然后进行一个50轮单因素训练；候选有稳定收益后再投入重复种子。

目标是提高precision、减少非目标区域预测，同时保住recall、六类Dice和边界表现。**这是一项可证伪的假设检验，不保证提高分数。** 不建议直接沿用A1配方、加大网络或同时加入更多增强、loss和scheduler。

## 2. 七模型告诉了我们什么

| 模型 | 最佳Validation小器官Dice | 既有Test小器官Dice | 可以支持的判断 |
|---|---:|---:|---|
| 2D | 0.77569 | 0.70822 | 有低显存价值；总体和端部较弱，但个例可优于3D；配方不同，不能纯归因于维度 |
| Standard | 0.85022 | 0.78510 | 强基线；较少远处Body误报，不应被“Improved”命名预设为较弱 |
| v1 | 0.84200 | 0.80778 | 一些类别与端部受益，但Body远处误报和HD95严重退步 |
| v2 | 0.83620 | 0.79590 | 独立监督＋主头推理未形成整体优势；不能把去掉相加输出当作已证实的修复 |
| v3 | **0.85636** | **0.81448** | 当前Validation主候选；GN替换值得保留，但有少数极端前列腺预测及患者依赖 |
| A0 | 0.84500 | 0.78365 | AdamW＋衰减＋cosine组合未超过v3，不能据此判定scheduler单独无效 |
| A1 | 0.82976 | 0.78012 | 远处Body误报更少，但不是更好的整体分割模型；当前几何增强配方不作为默认 |

Test列只总结已经发生的固定模型结果，不用其病例、排名或指标决定本方案参数。提出loss假设的直接依据来自下面的**Train与Validation**。

## 3. 当前证据支持优先处理什么

### 3.1 不是简单的“训练时抽不到小器官”

既有完整Train采样预演覆盖26患者、143个volume和50轮，共13000个原始均匀patch：

| 类别 | 含该类别的patch比例 | 体素占比 |
|---|---:|---:|
| Bladder | 86.12% | 2.569% |
| Rectum | 91.81% | 0.752% |
| Prostate | 96.08% | 0.646% |

这是预演轨迹的标签曝光，不代表每个小器官都被完整看见，也不直接测量端部或困难负例覆盖。但它足以反对“多数patch根本没有Prostate”这一解释。因此，不直接把更多前景过采样或更高类别权重作为第一步。

来源：`logs/audits/g7_edge_sampling_full_20261019/manifest.json`中的`summary.original_uniform.exposure`。该边界采样候选只做过CPU预演，未训练；通过机械门槛不能证明能改善v3。

### 3.2 Validation确实存在precision–recall差距

| 模型／类别 | Dice | Precision | Recall |
|---|---:|---:|---:|
| Standard／Bladder | 0.9303 | 0.9250 | 0.9366 |
| v3／Bladder | 0.9213 | 0.8921 | 0.9554 |
| Standard／Rectum | 0.7989 | 0.7401 | 0.8772 |
| v3／Rectum | 0.8186 | 0.7632 | 0.8906 |
| Standard／Prostate | 0.8215 | 0.7429 | 0.9266 |
| v3／Prostate | 0.8292 | 0.7857 | 0.8817 |

v3已相对Standard改善Rectum/Prostate的均值和部分平衡，但三个小器官仍均为precision低于recall；Bladder相对Standard的precision退步尤其值得注意。并非所有错误都来自同一原因，也不能只由precision低就认定loss有错。

### 3.3 极端前列腺错误有新增的连通性证据

同一Validation病例S022_Week6：

| 项目 | GT | Standard预测 | v3预测 | A0预测 | A1预测 |
|---|---:|---:|---:|---:|---:|
| Prostate体素数 | 534 | 1051 | 1018 | 956 | 975 |
| 6邻域连通分量数 | 1 | 1 | **2** | 1 | 1 |
| 预测z范围内空缺切片数 | 0 | 0 | **22** | 0 | 0 |
| Prostate HD95/mm | — | 7.087 | **106.116** | 7.408 | 7.408 |

v3最大分量占预测的87.03%，另外一个分量约132体素；GT在本例只有一个分量。J026_Week1的v3预测也有3个分量及21.10mm HD95。38卷Validation的GT Prostate均为一个6邻域分量。

这些记录支持“额外分离预测与极端距离共同出现”，但**尚未证明删除该分量能修复全部边界问题，也未确定其真实位置与形成机制**。不能把22个空缺切片直接解释为器官主体断成22处。

### 3.4 还存在分辨率与统计稳定性限制

Validation评估网格spacing约为X/Y 3.125–3.516mm，Z约3.120mm。毫米级表面分析受该网格影响；不能不加说明地承诺亚毫米边界。改善空间分辨率属于后续独立实验，不能混入本次loss消融。

每个配方目前只有一个种子，且6名Validation患者已被多轮研究复用。v3相对Standard的Validation均值只高0.00613。再次取得一点均值增长，不等于已经证明稳定泛化；需要后续成对重复或Train内部患者级交叉验证。

## 4. 文献如何支持这个优先级

| 原始文献 | 与本项目有关的结论 | 在本方案中的用法与限制 |
|---|---|---|
| [U-Net，2015](https://arxiv.org/abs/1505.04597) | 将数据增强用于有限标注样本的训练 | 支持考虑增强，但不保证我们当前旋转／缩放设置有效 |
| [3D U-Net，2016](https://arxiv.org/abs/1606.06650) | 体积卷积与在线弹性变形用于其分割任务 | 支持3D上下文与配对增强的研究价值；不据此直接增加强形变 |
| [Isensee等，BRATS贡献](https://arxiv.org/abs/1802.10508) | 用Dice应对类别不均衡，并结合其残差网络和增强方案 | 原论文不是对本项目额外高静态CE权重的验证；保留当前有效骨架，单独检验loss |
| [Tian等，Recall Loss](https://arxiv.org/abs/2106.14917) | 讨论固定提高少数类权重可能造成过多FP及低precision | 为弱化静态权重提供一般机制依据；不代表已证明我们的具体权重是根因，也不直接照搬其动态loss |
| [Kervadec等，Boundary Loss](https://arxiv.org/abs/1812.07032) | 将距离边界的信息与区域loss结合，应对高度不均衡问题 | 若后续确认边界误差是主要剩余机制，可作为独立候选；本次不同时加入 |
| [nnU-Net，Nature Methods](https://www.nature.com/articles/s41592-020-01008-z) | 强调预处理、架构、训练和后处理的配套配置 | 支持系统检查和受控比较，不等于增加一个模块就能复现其表现 |

文献提供可检验的方向，不提供本数据集必然提高的保证。以上只引用论文作者的原始来源。

## 5. 先做一个有边界的低成本诊断

**目的：解释v3异常分量，不再无限扩展诊断。**

固定v3最佳权重，不训练、不访问Test，针对S022_Week6、J026_Week1以及一例正常Validation对照生成三平面图和连通分量表，测量各预测分量的物理位置、体积、与GT重叠和距GT的距离。GT只用于事后评估，不参与构建推理区域。

可同时做一次明确分离的`v3 + largest-Prostate-component`敏感性实验：推理只根据预测连通域保留最大的Prostate分量，移除位置改分为六类logits中最优的非Prostate类别；不使用GT找ROI或决定移除哪些位置。对完整38卷Validation统一评估一次，记录全部类别与空mask状态，不扫描许多阈值。

- 若HD95显著改善而Dice／recall保持，说明异常分量解释了一部分表面距离尾部；这不证明训练根因已找到。
- 若收益很小或真实目标被删，停止该规则，不把它作为默认。
- 多个真实分量、错误的最大分量和连通的过分割都可能使规则失败。该处理依赖器官连通性假设，应检查Train标注；Validation GT单分量不证明所有未来患者如此。
- 即使有效，也单独命名为**v3后处理变体**，不能伪称新训练网络改善，更不承诺修复所有临床界面。

完成这项诊断后转入既定训练或停止，不再追加成串新预检。

## 6. 推荐下一次训练：v5-L

### 6.1 唯一主要变量

检验假设：**在已有前景Dice平衡项下，当前三个小器官的额外CE权重可能偏强；温和压缩它们可改善precision及定位，而不过度损伤recall。**

只对Bladder、Rectum、Prostate采用预先选定的平方根压缩，其他类别权重保持：

| 类别 | v3原CE权重 | v5-L候选CE权重 |
|---|---:|---:|
| Background | 1.453871 | 1.453871 |
| Body | 1.000000 | 1.000000 |
| Bones | 2.617199 | 2.617199 |
| Bladder | 4.498586 | 2.120987 |
| Rectum | 8.893215 | 2.982149 |
| Prostate | 9.699950 | 3.114474 |

这组具体数值是本项目的**建议实验点**，不是论文推荐的最优参数；不宣称数学上必定改善。只试一个压缩强度，避免将Validation变为大规模权重搜索。

loss仍为`0.5 × weighted CE + 0.5 × foreground Soft Dice`。不删除类别权重，不同时增加边界项。PyTorch加权CE的mean还会按目标权重和归一化，因此权重修改可能影响CE相对Dice的有效梯度，不能把实际梯度变化直接说成按某个倍数缩小；应记录两个loss分量及预测曝光。

### 6.2 保持不变的设置

| 项目 | v5-L安排 |
|---|---|
| 网络 | v3残差GN(1,C)骨架，Dropout=0.3，基础通道8 |
| 监督与推理 | 仍对main＋上采样half＋quarter logits之和训练并推理 |
| 优化器 | 与v3一致的Adam，固定学习率0.001，weight decay=0 |
| 数据与采样 | 同患者split、预处理、visit计划、均匀64×64×32 patch；不加前景过采样 |
| 增强 | 不加A1空间增强，也不加新的强度增强 |
| 预算 | 50轮、每轮130次更新、batch=2；不同时延长训练 |
| 初始化与顺序 | 首轮保持种子371017及v3相同初始化／患者／patch计划，另记运行环境；不承诺不同CUDA运行逐位相同 |
| 选模 | 沿用10个Validation候选及原患者均衡小器官Dice，同分取早 |
| 记录 | 原有保存／恢复、逐类precision/recall、混淆、表面距离与资源；补充CE/Dice分量，实际使用权重 |

**不从v3的50轮权重续训后，与从头训练v3直接作公平比较。** 本次候选从相同初始状态训练，使主要可解释差异是loss权重。若以后做fine-tuning，应给它单独的实验身份和额外更新预算说明。

### 6.3 为什么不先叠加其他常用方法

| 候选 | 当前优先级 | 理由 |
|---|---|---|
| 弱化三小器官CE权重 | 第一训练候选 | 与Validation precision–recall和已有Train不均衡处理直接相关；成本低、因素明确 |
| 独立scheduler消融 | 第二候选 | A0没有隔离scheduler；仍有研究价值，但不是已验证的失效修复，不与v5-L合并 |
| 端部／困难负例采样 | 条件候选 | 要先证明Train局部曝光不足；“含器官96%”既不排除局部不足，也不支持盲目提高前景比例 |
| 温和MRI强度增强 | 条件候选 | 可能帮助外观泛化，但当前无隔离证据；单独实验，不与loss同时改 |
| Boundary／surface loss | 后续候选 | 对精确轮廓有合理文献依据，但距离单位、梯度尺度和额外系数需要控制；本次不堆入 |
| 更高分辨率／粗到细网络 | 较后 | 当前约3mm网格确有限制，但会改变任务输入、成本与上下文，需要独立重建公平对照 |
| 大网络、Attention、Transformer、多模型ensemble | 暂不优先 | 当前没有容量不足是主因的证据；引入更多变量及成本，不利于回答已有失败机制 |

## 7. 如何判定成功、失败及是否继续

选模主指标不改变；安全相关指标作为是否采纳改进的额外报告／准入条件，不依据Test换checkpoint。

### 7.1 提升型结果

在固定Validation上：

1. 最佳患者均衡小器官Dice超过v3的0.856356；报告精确差值，不只保留四位小数制造并列或优势。
2. 六患者配对结果多数受益；Bladder/Rectum/Prostate的precision变化与该假设方向一致，并完整报告recall是否下降。
3. 不以牺牲某个前景类别、增加漏分割或更差HD95尾部来换平均值；初步准入可将“任一前景患者均衡Dice下降超过0.01”设为不接受的工程门槛，冻结前确认。0.01不是临床或统计显著性标准。
4. Prostate HD95的P95、最大值、患者均值，Body远处FP和OAR混淆同时报告；不只挑中位数。

若只改善HD95而Dice下降，报告为边界取舍或后处理结果，不称全面超越；若只在一例或一个种子有增益，视为初步信号。

### 7.2 可证伪与停止条件

- 权重压缩未提高precision、也未改善定位／表面尾部：本次“权重偏强”假设未获支持，不继续凭感觉叠加Focal/Tversky等loss。
- precision提高但recall或主Dice明显退步：说明它改变了权衡，未达到目标，不默认采纳。
- 只减少分离分量却保留连通外扩：后处理解释有限，需转向监督／局部边界，而非继续删分量。
- 出现真实标签／空间实现错误：先隔离修复并重新对照；不将实现修复包装成架构进步。

### 7.3 预算与泛化确认

第一轮只新增一个50轮v5-L，用既有v3作同配方历史对照。预计资源量级参考既有v3约2小时A100，但队列、IO和硬件状态会改变耗时；不是运行保证。原始v3仍保留，不被覆盖。

若有明确Validation收益，再使用一个预先固定的新种子（建议371018）分别训练v3控制与v5-L，共新增两个50轮run；必须允许两者的新随机轨迹一致配对。这样最多三次新训练，而不是一次开许多改进模型。若首轮失败或收益不足，停止。

现有Test不参与这一选择。重复种子也不能消除Validation已被反复研究的偏差；如课程资源允许，可讨论Train内部患者级交叉验证。不得把已查看的Test再次称为新盲测或用它挑压缩系数。

## 8. 当前应保留的研究结论

- v3是现有预定Validation准则下的主候选，Standard仍为重要参照，A1不是默认下一代基座。
- 我们尚未证明“高类别权重是错误根因”；下一次实验就是要检验它。
- 边界可靠性、分类precision和患者稳定性应与平均Dice一起提升；不能承诺一次新模型会明显超过所有旧模型。
- 先得到一个可解释、可复算的结果，再决定是否优化scheduler、增强或网络结构。暂不写入训练冻结配置，不提交GPU任务。
