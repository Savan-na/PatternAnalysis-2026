## 一、我希望本次沟通确认什么

目前已完成七组历史正式模型的统一Validation/Test评估，以及最新三组v5模型（C、L、S）的Validation筛选、真实分割错误分析及固定最佳权重的Test补齐评估。我希望请教：**现有工作是否已达到作业的实现与研究要求；接下来应优先完善交付和论证，还是继续训练；如需继续，哪一个改进最有研究价值？**

当前结果的简要判断：

- **综合候选仍为历史Improved v3。** 它在当前十模型的Validation选模指标和既有Test小器官平均Dice领先；最新v5的L、S在同期Validation对照C上分别下降0.011675和0.007745，暂不替换v3。

## 二、数据与统一评估方法

### 2.1 数据规模

| 项目 | Train | Validation | Test |
|---|---:|---:|---:|
| 患者数 | 26 | 6 | 6 |
| MRI体积数 | 143 | 38 | 30 |
| 用途 | 优化参数与训练采样 | 选择checkpoint及诊断问题 | 固定模型的描述性性能评估 |

六个类别：**Background、Body、Bones、Bladder、Rectum、Prostate**。按患者划分，同一患者的不同visit不跨集合。

**原始数据如何组织和读取：** 每个病例是某位患者在一次`Week` visit中的一对3D NIfTI文件：`患者ID_WeekN_LFOV.nii.gz`（MRI）与`患者ID_WeekN_SEMANTIC.nii.gz`（六类mask），例如`K018_Week4`。这里的`Week`是文件中的visit标识，不表示每位患者每周都有一卷；26名Train患者共有143卷。程序先按患者ID和Week配对文件，核对3D形状、空间变换及体素间距，再读取整卷并共同降采样、归一化MRI；同一训练visit的预处理结果会缓存以供重复裁剪。[病例发现与配对代码](../../code/hipmri_rewrite/splits.py)、[3D读取与预处理代码](../../code/hipmri_rewrite/data.py)。

**模型实际看到什么：** 每个epoch从每名Train患者的多个visit中按固定轮换规则选**一卷**，再从该卷抽10个配对的MRI/mask训练样本；26×10＝260个样本，batch size=2，因此是130次更新。Standard及Improved系列（包括v5 C/L/S）从完整3D体积的三个空间轴上均匀选择起点，裁出`64×64×32`体素的**3D块**，一次送入3D网络，不是每次只取一张2D切片。补充的2D U-Net才先选一个Z切片、再裁`64×64`像素的**2D块**；每患者10次抽样中4次均匀选切片、Bladder/Rectum/Prostate各2次器官感知抽样。两类模型都会在输入块内部用卷积核逐位置提取特征：2D模型用2D卷积核，3D模型用同时覆盖相邻切片的3D卷积核；抽取训练块与卷积核在块内滑动是两个不同步骤。[3D采样代码](../../code/hipmri_rewrite/sampling.py)、[2D采样代码](../../code/hipmri_rewrite/sampling_2d.py)、[卷积层实现](../../code/hipmri_rewrite/models/common.py)。

Validation/Test推理与训练抽块也不同：当前正式评估将**整卷降采样后的3D MRI**加必要的边缘padding后一次送入3D网络；2D网络则逐Z切片、每批最多8张处理，再拼回完整3D预测。[推理代码](../../code/hipmri_rewrite/inference.py)。

### 2.2 各模型共同遵守的条件

| 条件 | 实际设置 |
|---|---|
| 预处理 | MRI与mask共用网格，各轴降采样2倍；MRI线性插值、mask最近邻；按每个volume的非零MRI区域做Z-score |
| 训练预算 | 历史七组及最新v5三组均完成50个epoch；每轮130个batch、batch size=2，即每组6500次参数更新 |
| 患者采样 | 每轮每名Train患者取一个visit，按预定规则轮换；每患者取10个训练样本 |
| 模型输入 | 3D patch为64×64×32；2D crop为64×64 |
| 验证与选模 | 每5轮验证一次；从5、10、…、50轮共10个候选中选best，同分取较早轮次 |
| 主要选模指标 | 六名患者等权的Bladder、Rectum、Prostate三类平均Dice |
| 患者指标算法 | 先合并同一患者各visit的混淆矩阵，再计算指标，最后平均患者；不把30卷Test当30名独立患者 |
| 保存与复现 | 保存逐轮权重、训练记录、best及断点状态；固定配置和源码身份，保留中断与恢复记录 |

**说明：**“50轮训练”不是50个batch。Test已经在研究过程中被查看过，因此不能再将本次评估称为全新盲测。所有checkpoint均按Validation选定，没有从Test挑选最佳轮次。

## 三、十组模型分别改变了什么

### 3.1 模型结构与监督方式

| 模型 | 结构与宽度 | 归一化 | 残差／Dropout | 输出与监督 | 主要研究目的 |
|---|---|---|---|---|---|
| 2D U-Net | 标准2D U-Net，基础通道16 | GN，1组 | 无残差；无显式Dropout | 单输出头 | 提供逐切片、低显存补充对照 |
| Standard 3D | 标准3D U-Net，基础通道8 | GN，1组 | 无残差；无显式Dropout | 单输出头 | 建立3D基线 |
| Improved v1 | 残差3D U-Net，基础通道8 | InstanceNorm | 有残差；Dropout=0.3 | 主头、半尺度头、四分之一尺度头上采样后logits相加，对和计算loss | 引入残差与多尺度监督 |
| Improved v2 | 保留v1主体 | InstanceNorm | 同v1 | 三头分别计算loss，以1、0.5、0.25加权并除以1.75；推理仅主头 | 检查监督与输出融合方式的作用 |
| Improved v3 | 从v1修改；**不是从v2修改** | 14处IN替换为GN，1组 | 同v1 | 恢复／保留v1的logits相加方案 | 单因素考察归一化改变 |
| v4 A0 | 同v3 | GN，1组 | 同v3 | 同v3 | 同时将Adam改为AdamW、加入0.00001权重衰减，并将固定学习率改为逐步余弦衰减；不加空间增强 |
| v4 A1 | 同v3 | GN，1组 | 同v3 | 同v3 | 保持A0的AdamW、权重衰减及余弦学习率，另外以30%概率对MRI和mask同步施加三轴±10°旋转及0.9–1.1倍缩放 |
| v5 C | 同v3，为同期对照 | GN，1组 | 同v3 | 同v3 | 与L、S同期重复v3配方 |
| v5 L | 同C | GN，1组 | 同C | 同C | 仅对Bladder、Rectum、Prostate的CE权重取平方根 |
| v5 S | 同C | GN，1组 | 同C | 同C | 仅对Adam加入逐次更新的余弦学习率衰减 |

标准U-Net使用池化和转置卷积上采样；Improved系列使用带步长卷积及插值上采样后的卷积，激活函数也不同。因此Standard与v1并非仅相差一个模块。Improved为参考Isensee等论文思想的HipMRI适配实现，不声称完整复刻原论文。

|---|---|---|---|---|---|
| 2D | Adam | 固定0.001 | 0 | 患者均衡＋器官感知2D crop | 无 |
| Standard | Adam | 固定0.001 | 0 | 患者均衡＋均匀3D patch | 无 |
| v1 | Adam | 固定0.001 | 0 | 同Standard | 无 |
| v2 | Adam | 固定0.001 | 0 | 同Standard | 无 |

| A1 | AdamW | 同A0 | 同A0 | 同A0 | 30%概率；物理XYZ各轴±10°旋转、0.9–1.1倍各向同性缩放 |
