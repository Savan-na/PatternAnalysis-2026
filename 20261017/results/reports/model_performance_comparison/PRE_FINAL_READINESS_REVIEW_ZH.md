## 五、v3为什么可以保留，为什么不能称为绝对最好

| 比较点 | 审查结论 |
|---|---|
| 与Standard的原Validation指标 | v3高0.00613，6名患者中5名提高 |
| 与Standard的既有Test三小器官均值 | v3高0.02938，但仅3/6患者提高；M015带来较大收益，不能说人人受益 |
| 五前景整体 | v3的Validation/Test均值均为十模型最高 |
| 前列腺单类 | v3 Test 0.74850只比Standard 0.74329高0.00521；C为0.76327，高于v3 |
| 新前列腺50%重点分数 | Test C=0.82102、v3=0.82012；仅差0.00090，且这是事后分析，不用于重选历史模型 |
| 前列腺边界尾部 | v3 Test最大HD95约115.37mm，Standard约19.23mm；v3中位数较好不消除严重个例 |
| 复现与随机性 | v3和C相同seed及配方却未完全数值重现，Test三小器官相差约0.01047；这不是独立种子的重复验证 |
| 泛化结论 | 仅6 Test患者、反复查看的同一队列，没有多种子或外部队列；不能声称全面泛化优势或临床可用 |

因此，**保留v3是基于预先约定标准和整体权衡的合理决策，而不是依据最新Test追认一个绝对冠军。** C的原始证据必须归档保留，即使最终活跃实现只剩Standard与v3。

## 六、短期还值得继续训练吗

**当前建议：不继续启动新训练。** 已测试监督、归一化、优化器/学习率、配对空间增强、类别权重，以及同配方对照。它们中没有已验证的稳定全面升级方案。当前额外价值主要在整理证据、清楚呈现失败与完成交付要求。

不能由这些实验推导“短时间不可能更好”：尚未完成第二种子、独立患者交叉验证、强度增强、单独边界目标等所有可能路线；即使只换随机种子也可能出现更高数值。更高单次分数仍不等于更可靠方法。

只有在导师明确要求更强稳定性证据且预算允许时，再考虑Standard与v3的匹配第二种子确认；它是可选科学增强，不是目前PDF写明的强制要求。本轮不提交此类作业，也不再用Test寻找配方。
