# 全部模型简明报告：排除Background，以前列腺为重点

## 1. 直接结论

**目前不能说某个Improved在所有方面明显超过Standard。**

- 看五类前景整体分割：**v3最好**。
- 看前列腺Test Dice：**C最好**；但Standard的前列腺最大边界错误较小。
- 当前列腺占50%时：**C略高于v3，仅差0.00090**，不足以证明稳定优势。
- L、S未整体超过同期C；A1没有实现全面提升。
- 建议保留v3为既有主要候选、Standard为强基线，C作为同期复现和前列腺方向的补充证据。

## 2. 这次怎么算

**Background不进入本报告的得分、逐类图或平均值。** 保留Body、Bones、Bladder、Rectum、Prostate。

1. 单类Dice：`2TP / (2TP + FP + FN)`。背景与前景之间的错分仍计入该类FP/FN；排除Background不是忽略这些错误。
2. 先合并同一患者所有visit的混淆计数，逐类计算Dice，再对6名患者等权平均。
3. **五前景等权Dice**：五类Dice相加除以5，避免Background接近1抬高平均数。
4. **前列腺重点Dice**：`0.50×Prostate + 0.125×(Body + Bones + Bladder + Rectum)`。Prostate权重是其他每类的4倍。

50%是本次分析约定，**不是老师规定的权重，不是训练loss，也不是新的checkpoint选择规则**。每个模型仍使用原先Validation患者均衡三个小器官Dice选出的best，不根据Test或这次加权重新挑轮次。重新读取50轮记录并核对固定Test文件及输入哈希，从混淆计数复算；不重新训练，不改写原始结果。

## 4. 每个模型说明了什么

| 模型 | 有价值的结果 | 主要问题 / 判断 |
|---|---|---|
| 2D | 低显存、逐切片对照；个例可优于3D | Test前列腺0.661低于0.7；不作为最终Hard候选，配方不同也不是纯维度消融 |
| Standard | 稳健的强基线；Test前列腺HD95最大约19.23mm | 仍有漏分、端部及困难患者问题 |
| v1 | 比Standard的五前景平均和前列腺Test Dice高 | Body远处误报严重，平均数较高不等于更可靠 |
| v2 | 部分边界比v1改善 | 独立监督未产生新的整体优势 |
| v3 | 五前景整体最好，原预设Validation指标也最好 | Test前列腺Dice只比Standard高约0.00521，最大HD95约115.37mm |
| A0 | 部分误报和边界尾部收敛 | 小器官表现未超过v3，优化器/日程组合未产生预期净收益 |
| A1 | 远处Body误报较少 | 前列腺和整体下降，空间增强没有带来全面提升 |
| C | 前列腺Test Dice最高，重点加权分数略高 | 前列腺最大HD95仍约86.84mm；同v3配方却结果不同，提示稳定性限制 |
| L | Validation膀胱改善 | 前列腺及整体未超过C，部分误报和边界恶化 |
| S | Test远处Body误报少于C | 前列腺及整体低于C；不能据此推广为所有学习率日程无效 |

**关键取舍：**C的Test Prostate Dice相对Standard高约0.01998，但前列腺最大HD95明显更差。即使以前列腺为重点，也不能只看重叠得分，应同时检查precision、recall、HD95和真实轮廓。
