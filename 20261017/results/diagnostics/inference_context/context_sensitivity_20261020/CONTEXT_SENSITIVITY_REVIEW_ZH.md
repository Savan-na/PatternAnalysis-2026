## 如何解释

### 本轮结论：有上下文敏感性证据，未通过直接替换推理方案的条件

Improved 四例的 ≥20 mm 远处 Background→Body 误检合计从 **153,886 降至 30,148（减少 80.41%）**。这是四个预选病例的体素总数，不是完整验证集结果；原始八组整卷混淆矩阵均精确复现 G5，输入来源和全部下载文件已核对校验和。

不能只看误检数量：K018 的 Body HD95 从 **125.632 升至 132.422 mm**，膀胱 Dice 从 **0.7327 降至 0.5837**。K008 的前列腺 Dice 从 **0.8454 降至 0.7944**，膀胱也下降。Improved 的 Rectum 在四例均有改善，但小器官并未全部保住。Standard 的膀胱和前列腺在四例中均下降，K018 的膀胱下降约 0.234。Standard 远处误检总数为 90→168，绝对数仍较小，不能用相对百分比夸大其退步。

误检体素数与 HD95 测量的对象不同：前者数的是距真实 Body 至少 20 mm 的背景误判，后者是双向表面距离的 95 分位数，取决于残余误检的空间位置和表面分布。因此误检减少不保证 HD95 同步下降。K018 图片仍可见体积边缘的远处残余预测；这不能单独证明它们具体贡献了多少 HD95。

### 辅助头揭示的是共适应，不是单一“坏头”

在同一组 Improved 整卷远处误检体素上，四例的 combined Body−Background margin 中位数均从正转负：

| 病例 | combined：整卷 → 滑窗 | quarter：整卷 → 滑窗 |
|---|---|---|
| K018_Week4 | 1.277 → -1.730 | -2.133 → -5.230 |
| B040_Week4 | 0.848 → -2.129 | -2.987 → -5.981 |
| J026_Week4 | 1.406 → -4.005 | 1.505 → -5.046 |
| K008_Week0 | 0.584 → -1.697 | -4.545 → -6.933 |

quarter 的变化尤其明显，但方向并不总是错误：K018、B040、K008 的 quarter 原本就在抵消其他头的 Body 倾向，而 J026 原先偏向 Body。因此不能据此删掉 quarter 或整个 Deep Supervision。不同头的中位数不可直接相加；逐体素相加残差在原始 JSON 中另行核对。Standard 在相同误检参考体素上的整卷 margin 中位数约为 -7.87 至 -9.04，表明其原模型在这些区域已有较强的 Background 倾向。

### 下一步决定

1. **保留原整卷协议作为已报告的 G5/G6 结果，不用本轮滑窗替换。** 四例不足以选择最终协议，小器官损伤也使“直接扩展为候选方案”的条件未满足。
2. **停止窗口和融合参数扫描，暂不扩至全部 38 例。** H4 得到敏感性支持，但上下文、padding、感受野及归一化范围同时变化，尚无单独的 InstanceNorm 因果证明。
3. **按 P1 转入已通过 Train 审计的 G7 采样单因素实验。** 下一项对比保持 Improved 结构、损失、优化器、更新预算、初始化种子及原整卷验证协议一致，只改变原均匀采样与 9+1 边缘采样。新候选应独立运行，不能从第 50 轮继续训练后与原 50 轮模型直接声称采样收益；先核对可复用参考运行的完整身份与训练预算。
4. 同时跟踪六类指标、逐患者三小器官表现和 Body HD95；预先记录边界评估规则，不在看到新结果后改选模标准。若 G7 仍不能改善取舍，再考虑“各辅助头独立损失、主头推理”的受控结构实验，继续保留残差与 Deep Supervision。

本轮没有训练、没有新的 Test 评估，也没有证明 Improved 已超过 Standard。

- 若改善很弱或小器官受损，按 P1 转向已有审计的 G7 单因素训练；不继续扫描滑窗参数。
